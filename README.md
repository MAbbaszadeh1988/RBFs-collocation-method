# RBFs-collocation-method
"Some MATLAB code has been uploaded, utilizing the RBF collocation method for solving certain PDEs."
📌 Overview
This repository contains an implementation of the Radial Basis Functions (RBFs) Collocation Method for solving partial differential equations (PDEs). The method uses radial basis functions as trial functions in a collocation framework, providing a meshfree approach for numerical solution of boundary value problems.
